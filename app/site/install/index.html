Install on your phone or computer

Last updated 2026-10-17

Open the app in your browser.

Android

In Chrome, open the browser menu and choose Install app or Add to Home screen.

iPhone and iPad

In Safari, tap Share, then Add to Home Screen.

Desktop

Chrome and Edge offer Install in the address bar or browser menu.

Installation does not enable background notifications by itself. No signed APK download is offered.
