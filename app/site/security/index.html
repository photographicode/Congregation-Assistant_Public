Who can see your congregation’s data?

In Standard mode, the service runs on a cloud database. The service operator can technically reach it with production credentials. Role restrictions in the app do not remove that operator ability.

Support Access and Private mode are not offered as active protections in this release. Ask us about access controls before sharing sensitive records.

RoleApplication access

Service operatorTechnical database access in Standard mode

What protects your data?

The app uses Google sign-in, per-congregation database access rules, input validation and encrypted backup files. Generated PDFs are created in your browser. Treat downloaded documents as private records.

HTTPS protects requests to the hosted service. Supabase provides the database. The configured region is Mumbai, India (Supabase ap-south-1).

Assistant (on-device)

Runs on your device. What you type to the assistant is not sent anywhere, not used to train anything, and not kept after you close it (history is off). Records you confirm are saved the same way as any other record. Authorized records are loaded before the panel opens; confirmation submits structured report values to the normal backend. No cloud AI model is used.

Pools and permissions

Department overseers request publishers; the main administrator approves pool membership. Assignment views expose limited roster information and server checks enforce congregation and department scope. Cleaning currently supports individuals; group rotation remains in development.

Your choices

Administrators can export records and create encrypted backups. Share documents only with authorized recipients. Contact support@congregationassistant.com for deletion requests until self-service deletion is available.

Providers

  • Supabase — database and authentication
  • Cloudflare — planned custom-domain hosting
  • Google — account sign-in
  • Titan — support email
  • Your chosen sharing app — only when you share a document or message

How we test

Automated checks cover layout, contrast, import parsing, report rules and PDF fixtures. Isolation and operational controls are not presented as independently audited. A third-party security review is planned.

The practical limits

Downloaded exports, device access and the service operator’s production credentials need careful handling. No online service can remove every risk. We will describe material incidents and the actions taken.

Report a problem

Write to security@congregationassistant.com. Include the affected page and steps to reproduce; avoid sending congregation records. See security.txt.
