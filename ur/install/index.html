Congregation Assistant

Keep the app close.

Open Congregation Assistant in your browser. In Settings, choose Install app. The app first tries your browser’s install prompt.

Android

Chrome: browser menu → Add to Home screen → Install. Samsung Internet: menu → Add page to → Home screen. Firefox and Edge offer Install or Add to phone in their menu.

iPhone and iPad

Safari: Share → Add to Home Screen → Add.

Desktop

Chrome and Edge: use the address-bar install icon, or the browser menu’s app installation option.

Installed? Open it from your home screen. Installation alone does not enable background notifications.
