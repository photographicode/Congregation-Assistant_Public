Frequently Asked Questions

Do publishers need to install an app?

No. Unlike other tracker apps, Secretary Assistant uses standard web links. You send a link via WhatsApp or SMS, and they open it directly in their phone's browser. There are no PINs to remember and nothing to download, making it perfectly suited for elderly publishers.

Is congregation data secure?

Yes. Data is stored securely on enterprise-grade cloud databases (Supabase). The secretary's portal is locked behind a unique Tenant ID and a strict master password. Furthermore, we include a "Danger Zone" feature that allows you to permanently wipe all congregation data within 24 hours if requested.

Can Group Overseers see reports?

Yes. You can generate a specific read-only link and set a password for each Group Overseer. They can log in to see exactly who in their group has submitted a report and who is pending, without having access to the rest of the congregation's data.
